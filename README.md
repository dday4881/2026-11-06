## 1. 주요 결과 (Key Metrics)
본 실험에서는 개별 이미지 단위의 객체 탐지(Detection) 모델을 확장하여, 동영상 파일(`demo.avi`)의 연속적인 프레임 스트림 내에서 동일 객체에 고유 식별 번호를 부여하는 영상 추적(Object Tracking) 파이프라인을 구축하고 그 성능을 검증하였습니다.

### 1.1 입력 미디어 사양 (Media Specifications)
* **입력 소스:** `data/demo.avi`
* **프레임 레이트 (FPS):** OpenCV `CAP_PROP_FPS` 인터페이스를 통해 원본 동영상의 고유 FPS 추출 및 반영 완료
* **해상도 (Resolution):** 원본 비디오 행렬 크기 감지 및 연동 (`size` 변수 자동 지정)

### 1.2 최종 산출물 및 데이터 배출 현황
* **비디오 결과물:** `p07_tracked.avi` (ByteTrack 시각화 경계 상자 및 ID가 렌더링된 비디오)
* **메타데이터 CSV:** 
  1. `p07_predictions.csv` (Validation 이미지 세트 단일 추론 결과)
  2. `p07_frames.csv` (프레임별 탐지 객체 수 시계열 로그)
  3. **`p07_tracks.csv`** (프레임별 객체 고유 Track ID, 좌표, 클래스, 신뢰도 종합 기록)

## 2. 결과 해석 및 기술 분석 (Technical Analysis)

### 2.1 스트림 처리 알고리즘 구조 검증 (B08 구역)
* 비디오 파일 전체를 물리 메모리에 한 번에 적재할 경우 발생하는 시스템 오버헤드 및 버퍼 오버플로우를 차단하기 위해 **`stream=True` 제너레이터(Generator)** 아키텍처를 도입하였습니다.
* **`persist=False` 설정의 기술적 의의:** 새로운 비디오 스트림이 시작될 때 이전 추록 세션의 추적 상태(Tracking State)가 오염되거나 전이되지 않도록 추적 메모리를 초기화하여 독립적인 파일 분석의 무결성을 확보하였습니다.
* **ByteTrack 알고리즘 적용:** 신뢰도(Confidence)가 낮은 예측 상자도 무조건 폐기하지 않고, 프레임 간의 유사도 및 이동 궤적을 고려하여 두 번째 매칭 단계에서 구제하는 효율적인 객체 연관성 로직을 활성화하였습니다.

### 2.2 실계측 데이터 정형화 및 예외 처리 (B09 구역)
* 연속 루프 내에서 수집된 다차원 데이터 행렬인 `tracks` 리스트를 Pandas 데이터프레임 구조로 변환 후 `index=False` 및 윈도우 인코딩 규격(`utf-8-sig`)을 지정하여 유실 없는 CSV 입출력을 구현하였습니다.
* 추적 컴포넌트(`result.boxes.id`)의 유효성 검사 구문(`if ... is not None:`)을 배치하여, 객체가 일시적으로 화면에서 사라지거나(Occlusion) 탐지 수가 0건인 프레임에서도 인덱스 참조 에러(`TypeError`)가 발생하지 않도록 예외 처리를 완벽히 설계하였습니다.
